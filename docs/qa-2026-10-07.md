## Corrections required by live qualification

The native subprocess must receive actual stdin EOF before awaiting Go's bounded
JSON reader. Peer-issued delegation expiries need bounded clock tolerance while
remaining capped by the receiver's local lifetime. The pinned upstream verifier
needs its exact public GitHub/AMD proxy destinations in the egress allowlist.
These changes preserve hardware and cryptographic checks.

Tinfoil previously returned authenticated success without emitting
`ResponseVerified`; the gateway correctly rejected that incomplete contract.
The owning shared client now emits it after existing authentication/accounting
checks. The gateway's event-and-return requirement remains intact. Shared tests
passed (75, two existing ignored), plus clippy and a real event-ordering canary.
Gateway CI and platform hosted-web CI passed.

Cloudflare uses manual body encoding for precompressed verifier WASM to prevent
double gzip. Fonts stay on the same origin under CSP. Catalog refreshes preserve
available user selections instead of resetting them to the first provider.
